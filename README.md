# Best-Selling Albums Analysis

This repository contains an analysis of a best-selling albums dataset. The analysis lives in `babydataanalysis.ipynb` and includes visualizations and explanations that examine temporal trends, top artists, country-level patterns, and artists with multiple best-selling albums.

Data source: https://www.kaggle.com/datasets/ciroduro01/best-selling-albums-of-all-time

Files included:

- `babydataanalysis.ipynb` - interactive Jupyter notebook with code, charts, and narrative
- `babydataanalysis.html` - exported HTML version of the notebook (if generated)
- `babydataanalysis.md` and `babydataanalysis_files/` - exported Markdown and associated images
