# Best-Selling Albums Analysis

This repository contains an analysis of a best-selling albums dataset. The analysis lives in `albums_analysis.ipynb` and includes visualizations and explanations that examine temporal trends, top artists, country-level patterns, and artists with multiple best-selling albums.

Data source: https://www.kaggle.com/datasets/ciroduro01/best-selling-albums-of-all-time

Files included:

- `albums_analysis.ipynb` - interactive Jupyter notebook with code, charts, and narrative
- `analysis exports/babydataanalysis.html` - exported HTML version of the notebook (if generated)
- `analysis exports/babydataanalysis.md` and `analysis exports/babydataanalysis_files/*.png` - exported Markdown and associated images
- `datasets_join.ipynb` - joining notebook for an assignment
